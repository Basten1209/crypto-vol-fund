# Cap 25% Comparison Note

## Benchmark Framing

- Primary comparison should be minimum variance versus equal-weight, because both use the same selected 50-asset universe and rebalance cycle.
- BTC HODL remains useful market context, but it should not be the main benchmark for judging whether the allocation rule improves on a naive portfolio.

## Readout

- Cap 25% materially reduced concentration: Phase 5 top weight max fell from 92.06% to 25.00%.
- Cap 25% improved total return and max drawdown versus the uncapped minimum variance run.
- Cap 25% increased annualized volatility and turnover versus the uncapped run.
- Against equal-weight, cap25 minimum variance still shows lower squared-return loss in the DM test for both cycles.

## Implication

Cap 25% is a better capstone-project candidate than the uncapped portfolio because the product story is more credible: it limits single-name concentration while preserving the equal-weight risk-reduction result. The remaining weakness is that absolute returns are still negative over this sample, so the final narrative should emphasize risk-controlled allocation rather than return outperformance.
